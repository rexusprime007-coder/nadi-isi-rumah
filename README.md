# Nadi Isi Rumah

Interactive dashboards that turn Khazanah Research Institute's **State of Households 2026** report into visual data stories for Malaysia — income vs spending by state, happiness, and what the numbers mean for households.

Built by **Ahmad Muazamil bin Ishak** with Claude.

## Projects

| Folder | What it is |
|---|---|
| [`nadi-isi-rumah/`](nadi-isi-rumah/) | "Daily pulse" style dashboard — dark KPI cards, happiness petal chart, income vs spending bars by state, state table |
| [`nadi-isi-rumah-plus/`](nadi-isi-rumah-plus/) | Extended version — key takeaways, six data stories and implications for Malaysia |
| [`rasa-isi-rumah/`](rasa-isi-rumah/) | Animated scroll story — state map, state tiles with mini lines, pictograms and rings that build as you scroll |

Each folder is a single self-contained `index.html`. Open it in any browser, no build step needed.
